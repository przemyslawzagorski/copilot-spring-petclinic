# Materiały szkoleniowe

- Pisz po polsku, konkretnie i krok po kroku.
- Nie zmieniaj numeracji ćwiczeń bez aktualizacji `START_HERE.md`, `EXERCISES.md` i mentora.
- Polecenia muszą zawierać wariant właściwy dla wspieranej platformy.
- Rozróżniaj funkcje Copilota, Claude Code i Augmenta; nie przypisuj funkcji jednego narzędzia innemu.
- Linkuj do oficjalnej dokumentacji i zaznaczaj funkcje preview lub ograniczenia platformowe.
- Po zmianach uruchom `validate_modules.ps1`.
